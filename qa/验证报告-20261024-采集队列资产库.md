## 4. 兼容与回滚

1. **旧 App + 新 Server**：`gather.v2` 缺失 → `ServerFieldTasks.gatherLegacy`（原方法体逐字节保留）。
2. **新 App + 旧 Server**：`applyTo` 同时写旧键投影（min_level/resources_named/max_queues/strategy.send/alliance_mine/formation_*），旧 Server 可继续派队。
3. **资产库读侧回滚**：`VAULT_ASSET_LIBRARY=off` → 容量/体力等读取回退旧逻辑（attach/投影不影响）。
4. **采集设置页回滚**：功能页「旧版参数（兼容）」保留原弹窗入口（只写旧键、不清 v2）。
5. **未触碰**：`VAConfig.gradle`、许可证/支付/更新等无关模块；批次11 改动已在独立提交 `913b5c4`，本分支只含本次功能。
