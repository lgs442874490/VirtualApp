## 数据模型与接口变更

- 新增持久化：`data/migrant.json`（任务 + attempts，原子写 + .bak）
- 新增 HTTP：`POST /v1/vault/migrant`，`op=vaultMigrant`，`action` 分发 14 个动作
- 既有接口语义不变；`SessionKeeper` 仅新增方法，不改既有行为

## 依赖与风险

- R1 协议实测不确定 → 以原版源码移植为主，实测复核；不一致以实测为准
- R2 活动窗口稀缺 → 验收等真实窗口；先验 precheck 与拒答路径
- R3 多任务同时上号会话互踢 → 沿单会话约束错峰；发射只需在线+提交
- R4 真实资产消耗 → 仅专用角色，全程留痕

## 回滚方案

- 关入口：`FeatureGate.IMMIGRATION` 置回 `false`
- 停服务端：注释 Main 中 migrant 三行构造/启动（或 `attachMigrant` 不调用 → 端点返回 3002）
- 数据表 `migrant.json` 不回滚不影响旧功能
- 全部为新增包/新增入口，不触碰既有任务链路

## 测试策略

- 单测：`MigrantRules` 评估、50ms 节拍（注入假时钟）、状态机、`MigrantJobStore` 存取恢复、`MigrantApi` 参数校验
- 联调：端点级快照比对（字段名与网页版一致）
- 真机：M5/M6 按 V1–V9；报告归档 `qa/`
