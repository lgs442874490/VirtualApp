## 1. 背景与范围

「起号+注册」模块需要服务端对接两家接码平台自动取号/收码：**D1（d1jiema）与豪猪（haozhuma）**。
本期（M2）只做**纯库 + 单测**：不挂 HTTP 路由、不做凭据加密存储（M3 批次做）、不真实外呼（单测全部注入假 transport）。

## 2. 平台 API 规格（实现依据）

### 2.1 D1（d1jiema）
- 基地址：`https://api.d1jiema.com/zc/data.php`（GET，UTF-8）
- 鉴权：`token` 参数（用户在 D1 网页「个人中心→API对接中心→创建 API Token」获得）
- 调用形如 `?code=<操作>&token=<token>&<业务参数>`，业务参数空值不传
- 操作码：
  | code | 参数 | 语义 |
  |---|---|---|
  | `leftAmount` | - | 查余额 |
  | `getPhone` | `keyWord`（短信关键词，如「点点互动」）、`phone`（可选指定号）、`province`、`cardType`（实卡/虚卡） | 取号 |
  | `getMsg` | `phone`、`keyWord` | 取码（短信须含关键词） |
  | `release` | `phone` | 释放号码 |
  | `block` | `phone` | 拉黑号码 |
  | `queryUsed` | - | 最近 24h 历史（≤1 次/分钟，本包不封装） |
- 响应：**纯文本**；`ERROR:` 前缀 = 错误（后接错误描述）；成功时 data 文本格式上游未文档化（号码/验证码/余额的具体文本形态留待真实轮校准）——解析器必须宽容：先尝试 JSON 解析，失败则按「提取第一段连续数字（余额/验证码场景）或第一行非空文本（号码场景，11 位手机号优先）」提取，保留 `raw` 字段返回。

### 2.2 豪猪（haozhuma）
- 基地址：`https://api.haozhuma.com/sms/`（GET，UTF-8；UA 建议常规浏览器 UA，真实轮若被拒再调）
- 鉴权：`api=login&user=<账号>&pass=<密码>` → JSON `{code:"0", token:"..."}`；token 内存缓存复用，失效（后续调用报 token 错误）时自动重登一次
- 调用形如 `?api=<操作>&token=<token>&<业务参数>`，业务参数空值不传
- 操作：
  | api | 参数 | 语义 |
  |---|---|---|
  | `login` | `user`、`pass` | 换 token |
  | `getSummary` | `token` | 余额/摘要 |
  | `getPhone` | `token`、`sid`（项目 ID，数字）、`phone`（可选指定）、`isp`、`Province`、`ascription`、`paragraph`、`exclude`、`author=adminzfz` | 取号 |
  | `getMessage` | `token`、`sid`、`phone` | 取码 |
  | `cancelRecv` | `token`、`sid`、`phone` | 释放 |
  | `cancelAllRecv` | `token` | 全部释放 |
  | `addBlacklist` | `token`、`sid`、`phone` | 拉黑 |
- 响应 JSON：`code` ∈ {"0","200"} 成功；`code="-1"` 且 `msg` 含「等待」= 短信未到（轮询继续）；其余失败抛错带 `msg`
- 取码结果：`yzm` = 验证码字段；`sms` = 短信全文；兜底用正则 `(?<!\d)(\d{4,8})(?!\d)` 从 sms 提取首个 4-8 位数字
- 轮询参数由调用方控制（SDK 默认 15s 间隔 / 180s 超时，本包不内置线程）

## 3. 交付物

新建包 `vault-server/src/main/java/com/carlos/vaultserver/sms/`：

### 3.1 SmsProvider.java（接口）
```java
public interface SmsProvider {
    ProviderStatus testConnection();                      // 只验证凭据+余额，不取号
    PhoneOrder acquireNumber(String keyword) throws SmsException;   // 取号；keyword 对 D1=keyWord、豪猪由 sid 项目绑定（可为空）
    SmsMessage fetchSms(PhoneOrder order, String keyword) throws SmsException; // 取一次码；未到返回 waiting=true
    void release(PhoneOrder order) throws SmsException;   // 释放
    void block(PhoneOrder order) throws SmsException;     // 拉黑
    String name();                                        // "d1" / "haozhuma"
}
```
公共结果类型（独立文件或接口内嵌套，风格对齐 M1 PassportResult）：
- `ProviderStatus{boolean ok; String balanceText; int maxNumbers; String credentialMask; String error}`（maxNumbers 平台不返回时为 -1）
- `PhoneOrder{String phone; String providerData /*平台附加数据，如豪猪 sid/order 标识*/}`
- `SmsMessage{boolean waiting; String code; String content; String raw}`
- `SmsException extends RuntimeException`（独立文件，消息含平台名+操作+上游错误，**不得含 token/密码**）

### 3.2 D1SmsProvider.java
- 构造：`String token, String baseUrl /*默认 data.php*/, Transport`
- 嵌套 `interface Transport { String get(String url) throws IOException; }`（生产实现 `HttpUrlConnectionTransport`：HttpURLConnection，10s/15s 超时，常规浏览器 UA；单测不碰）
- 每个操作拼 query（URLEncoder UTF-8，空值剔除），按 §2.1 解析：`ERROR:` 前缀 → SmsException（内容=前缀后文本）；否则按宽容解析提取 phone/code/balance。
- `fetchSms`：D1 语义为「拉一次含关键词短信」——未到时上游返回形态未知：若解析不到验证码则返回 `waiting=true`（不抛错），注释标注真实轮校准点。
- `credentialMask`：token 用 `PassportIds.mask`。

### 3.3 HaozhuSmsProvider.java
- 构造：`String server /*默认 https://api.haozhuma.com/sms/ */, String user, String password, String sid, Transport`
- token 生命周期：懒登录→内存缓存；任何调用遇上游 token 失效错误（msg 含「token」或 code 非 0/200/-1）先重登一次再重试一次，仍失败抛 SmsException。
- 各操作按 §2.2；`fetchSms`：code="-1"+msg 含「等待」→ `waiting=true`；成功取 `yzm`（空则正则从 `sms` 提取）；二者皆空 → waiting=true。
- `testConnection` 走 `getSummary`：balanceText 取 `money/amount/balance` 第一个非空（宽容），maxNumbers 同理取 `maxPhone/limit` 类字段（无则 -1）。

### 3.4 SmsProviders.java（工厂）
`static SmsProvider create(String type, Map<String,String> config, Transport transport)`：type=`d1`→D1SmsProvider（token）；type=`haozhuma`→HaozhuSmsProvider（server/user/password/sid）；未知 type 抛 `IllegalArgumentException`。参数缺失抛明确中文错误。
