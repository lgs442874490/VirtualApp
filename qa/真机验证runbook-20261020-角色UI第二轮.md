## 2. 用例

### R1 账号页：全部工作区角色可见 + 每行可登录（需求 1）

1. 账号页切「列表」视图，找一个**工作区角色 > 4 个**的账号（没有就先进角色管理多开几个开关）。
2. **预期**：账号框内平铺展示全部工作区角色行（状态/昵称/区号/今日完成/上次登录/登录），**没有**「还有 N 个已启用角色」折叠链接。
3. 点某行「登录」：
   - **预期 toast 链**：「正在上传配置并登录服务器…」→「已登录并触发服务器自动化 · sid=xxx · 会话=online · 配置 N 项」；
   - **预期不启动游戏客户端**（容器/游戏不应被拉起；这是语义变化的关键判据）；
   - 按钮在请求期间显示「登录中」且不可重复点击。
4. 同服双角色账号（888 隆科多 uid=35371154 / 小鹿 uid=88280792）：两行分别点「登录」，
   **预期**每次服务器 `activeUid` 切到对应 uid（日志/toast 的 sid 相同但角色元数据跟随 uid 变化；
   可用 QA §3.4 同款方法核 `status_cache` 或角色表）。
5. 切完角色立刻下拉刷新/切页再回：**预期不回弹**（P2 防回滚两层仍生效——这轮登录入口也走了 `setCurrentRole`→`notifyRoleSwitched`）。

### R2 账号级登录仍可用（需求 1 附带）

1. 账号框头部长按 → 账号菜单 →「⏻ 登录并运行自动化」；或角色菜单。
2. **预期**：与旧行为一致（切主角色 → 上传 → 整轮），toast 同样带 sid/会话/配置数。

### R3 详情页角色盒（需求 2）

1. 账号页点账号头像区 → 账号详情页。
2. **预期**：角色卡标题「工作区角色（N）」；只列 enabled 角色；每行 = 昵称 + `K888 · UID … · 城堡 … 级 · 战力 …万` + 状态行 + 徽章（当前角色/工作区）+「登录」。
3. 找一个有未启用角色的账号：详情页**不应**出现未启用角色；空态/提示引导去「管理」。
4. 点右上「管理」→ 弹层打开某角色开关 → 关闭弹层 → **预期**详情页角色盒立即出现该角色（onChanged 刷新生效）。
5. 行「登录」→ 预期同 R1（只建会话不起客户端）；行点击 → 「已设为当前角色」+徽章移到该行。

### R4 角色管理弹层展示（需求 4）

1. 账号页点账号框右上「⚙ 角色管理」（或点任一角色行、或 ⋯ 菜单「👥 角色管理」）。
2. **预期**：
   - 每行 = 昵称（空→「未同步」）+ `K888 · UID 88280792 · 城堡 70 级 · 战力 20784万`；
   - **没有任何「同服第N角色」字样**；
   - 缺失字段显示对应「未同步」（uid 未知行显示 `UID 未同步`）；
   - 同服两行开关互相独立（开一个不影响另一个）；
   - 状态行与账号页角色行、今日页常驻状态三处一致。
3. 「+ 添加角色」跑一次发现：**预期**新角色默认未启用；发现完成后账号页/详情页列表刷新；若某行名字被修正，残留的旧 lv/战力/联盟被清零（P3 逻辑仍在）。

### R5 状态口径统一（需求 3）

1. 让某账号服务器在线（R1 登录后），依次看三处：账号页角色行状态列 / 今日页常驻在线状态 / 角色管理弹层角色行状态。
2. **预期**：同一状态源、同一文案（在线→「● 在线」/「在线 · 服务器」；重连中/被顶号暂停/需重导token 同理映射），不再出现旧口径混用（如账号页显示「日常在线」而今日页显示别的）。
3. 冷启动后立刻打开账号页（status 缓存可能还没到）：**预期**角色行显示「● 同步中」而非误报离线；几秒后刷新为真实状态。
4. （如可构造）顶号/掉线场景：三处同步变为「重连中」/「被顶号暂停」。

### R6 回归：既有防回滚/防串行逻辑不被 UI 改动破坏

1. 复跑 QA 报告 §3.1（切角色后立即触发状态拉取，不回滚）、§3.4（旧服务器 uid=0 回传不污染同服第一行——用 uid=0 的旧 server 或mock 回放）、§3.5（发现角色改名清残留元数据）。
2. **预期**：与上一轮结论一致（这轮只改 UI 与共享后半程，未动门控逻辑；但登录入口现在也走 setCurrentRole，需确认 R1.5 的不回弹）。

## 4. 已知限制（预期内，非缺陷）

- 本地模式（无服务器）下同服第二角色无法按 uid 细分在线态（LiveSession 无 uid）；App 启动即强制服务器模式，实际主口径不受影响。
- 行 uid 未知（未同步）时，服务器在线态保守不命中该行（显示离线/同步中），登录或发现一次后自愈。
- 「登录」保持整轮触发（fn=null）：若后续要「仅在线不跑轮」，需在弹层加开关——本轮按「模拟登录在线」语义交付。
