# 立项设计：行军类任务常驻化与资源锁体系

> 状态：立项设计（未开工）· 2026-10-06 · 前置：常驻会话灰度通过
> 对标原版：TaskEngine 资源锁（§4.6）+ 行军类任务的 interestedProtocols 驱动

## 1. 背景与目标

P3（PushWakeDriver）只覆盖了领取类任务；行军/养成类（采集 gather、狩猎 hunt、巨兽 behemoth、
情报 intel、竞技场 arena、练兵 barracks）刻意排除——它们会对世界状态产生**写操作**（派兵/开战），
并发触发会互相打架（原版用 6 种资源锁 + 竞技场独占窗防的正是这个）。

目标：让行军类任务也常驻化（推送/到点驱动），行为对齐原版，且不出现：
同一队列重复派兵、竞技场与采集同时出征、治疗与采集抢同一批兵。

## 2. 原版实现要点（取证）

- 6 种资源锁（每账号读写锁）：ACCOUNT_ACTION / WORLD_MARCH / FORMATION_HEROES / SOLDIERS / DIAMONDS / CLAIM_IDEMPOTENCY
- 任务优先级序：巨熊0 < 乱斗40 < 乔伊50 < 护盾100 < 领取200 < … < 后台400（抢占式排队）
- 竞技场独占窗（ArenaExclusiveGate）：执行与决策双层拦截
- 行军自动化循环：虚拟线程 + 看门狗（180s 超时重建连接）

## 3. 号库设计

### 3.1 会话内动作队列（最小锁集）

端侧单线程 actor 已天然串行，缺的是**任务间的互斥语义**。设计 `MarchCoordinator`
（每 LiveSession 一份）：

```
MarchCoordinator
  ├─ enum Resource { MARCH, SOLDIERS, DIAMONDS, ARENA }   // 端侧最小集4种
  ├─ Map<Resource, ReentrantReadWriteLock> locks          // 与原版同款读写锁
  ├─ 任务声明需求：gather→{MARCH_R, SOLDIERS_R}；hunt→{MARCH_R, SOLDIERS_R}；
  │   arena→{ARENA_W（独占）}；behemoth→{MARCH_W}；medic→{SOLDIERS_W}
  └─ tryRun(fnId, timeout)：拿不到锁→排队（优先级=原版序），超时让出
```

### 3.2 触发源扩展（PushWakeDriver 增补行军类）

| 推送 | 任务 | 原版对应 |
|---|---|---|
| notify_world_march_update（行军返回） | gather（补采集） | gather 19 推送之一 |
| notify_mapobj_update（野怪增刷） | hunt | hunt 地图推送 |
| notify_alliance_activity_update | behemoth（上车检查） | behemoth 世界 NPC 推送 |
| notify_intelligence_info | intel | intelligence 情报推送 |
| 定时：体力满/队列空轮询 15min | hunt/gather | 原版 10s/15s 间隔的保守版 |

冷却：行军类 15 分钟（比领取类 10 分钟更保守）。

### 3.3 数据与状态

- 无新增持久化表；队列/锁全内存（进程重启=重新评估，安全）。
- modState 增加行军占用状态行（`march:…:gather`："3 队采集中 · 下一队 12:30"）。

## 4. 风险与边界

1. **服务器单会话约束**（v3.7.1 实测）：行军类常驻只作用于常驻在线的那个角色；非当前角色
   到点任务仍走每日整轮（fresh 登录前关旧会话的既有机制）。
2. 体力/队列状态依赖 notify（notifies 表已有），漏推送时用 15min 轮询兜底。
3. 与游戏客户端互斥：顶号策略已处理（人玩优先让位）。

## 5. 里程碑

| 阶段 | 内容 | 验收 |
|---|---|---|
| M1 | MarchCoordinator 锁 + gather 接入 | 采集推送到达 15min 内补队；与每日整轮不冲突 |
| M2 | hunt/intel/behemoth 接入 | 体力利用率对齐原版（≥80%）|
| M3 | arena 独占窗 | 竞技场执行期间其它出征请求排队不丢 |

## 6. 工作量估计

M1 约 1 天（锁框架+gather）；M2 约 1 天；M3 半天。合计约 2.5 人日。
