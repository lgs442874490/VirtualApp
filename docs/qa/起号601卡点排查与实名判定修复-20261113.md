## 一、P1-1 实名判定修复（完成）

### 根因
上游实名响应是 **外层 `status` + `data.code`**，旧实现读 `data.status` / `data.error`（均不存在 → -1），
再用 `errorText()` 是否为空判通过——于是 `{"status":1,"data":{"code":2,"msg":"实名认证中…"}}`
被当成失败，整号被丢。

### 改动
| 文件 | 改动 |
|---|---|
| `passport/PassportClient.java` | `PassportResult` 保存 root，新增 `outerStatus()`（root.status）、`dataCode()`（data.code）；`status()` 标记 `@Deprecated` |
| `registration/RegistrationService.java` | 新增 `evaluateRealName()`：`status=1&code=1` 通过；`status=1&code=2` / `code=2406` / msg 含已实名关键词 → 已实名通过；status/code 双缺失 → 保留旧形状兼容；其余失败 |
| `registration/RegistrationServiceTest.java` | 新增 5 个用例（code=1 / code=2 认证中 / 2406 / msg 已实名 / 真失败 / status=0） |
| `bootstrap/BootstrapServiceTest.java` | 新增 601 复现用例 `upgradeFurniture_51_resetsThenCreates` |
