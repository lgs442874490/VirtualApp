## 3. 19 套内置编队实现口径

| # | 名称 | 英雄 | 兵力 |
|---|---|---|---|
| 1 | 巨兽 | 最强盾 / 波根(卢姆·波根) / 吉娜 | 1/0/0（按数量） |
| 2 | 狩猎 | 同巨兽 | 50/20/30 |
| 3 | 打熊队 | 盾：满星满专武尼莫(赫罗尼莫) → ≥4 星赫克托 → 尼莫/娜塔莉亚 → 最强盾；矛=米亚(缺→最强矛)；弓=最强弓 | 2/3/95 |
| 4 | 盾弓 | 最强盾 / 米亚→茉莉→最强矛 / 最强弓 | 49/2/49 |
| 5 | 盾矛 | 最强盾 / 最强矛 / 布拉德利→格雷格→最强弓 | 60/39/1 |
| 6~9 | 采集肉/木/煤/铁 | 队长 克劳瑞斯/尤金/查理/史密斯；单队长容量 >10 万只带队长，否则补 2 名不与其它采集队列冲突英雄；三兵种平均 | 34/33/33 |
| 10~19 | 熊上车1~10 | 队长 亨德里克/格温/书允/布拉德利/马格努斯/布兰琪/杰西/杰赛尔/赫罗尼莫/索尼娅；各补 2 名不冲突英雄 | 10/20/70 |

熊上车：与打熊队/彼此不重复（英雄级），按队长第一个远征技能排序（5 级优先按表顺序，其余按等级降序），**最多落库 6 队**；其余仅存在于 `all()` 备选，不写入编队库。采集/熊上车补位同时保证同队职业不重复（游戏每队列盾/矛/弓各一）。

## 4. 关键假设与降级

1. **尼莫 = 赫罗尼莫（50011）**：游戏内玩家常用简称；已用别名表映射。
2. **满专武 = `elv` ≥ 10**：专武 10 级封顶（社区资料）；`elv` 缺失时按 0，不满足“满专武”。
3. **第一个远征技能 = `skills` 槽 1**：真机帧中槽 0 恒为 1（基础技能），槽 1..3 为远征技能；老帧无槽 1 回退槽 0。
4. **服务端需重新部署**：`weaponLevel` / `expeditionSkillLevel` 由 vault-server 从 `notify_hero_init` 采集后下发；未部署新 server 时 App 两字段恒 0 → 打熊队退化为「4 星赫克托 → 尼莫/娜塔莉亚 → 最强盾」，熊上车退化为按表顺序取前 6（仍可用，但不是技能优先）。
5. **打熊队矛/弓**：用户只规定盾，取「米亚优先 + 最强弓」，并避开熊上车队长（防止挤掉熊上车4 布拉德利等）。
6. **采集平均**：34/33/33（合计 100；游戏界面按四舍五入显示 33/33/33）。
7. **名称长度**：保留网页版 30 字（游戏内为 1-3 字）；如需严格 1-3 字可后续单独调整。
8. 游戏编队只读；编辑走副本；不写游戏内编队槽（记忆恢复仍走既有服务端动作）。
