### 2.2 `bootstrap/BootstrapBatchRunner.java`（新文件）

- 批次：`id=bb+yyyyMMddHHmmss+序号`、config（serverId 必填、targetFurnaceLevel、allianceName 可空、roleName 可空、instantDiamond 等 BootstrapConfig 字段透传）、账号清单 `List<AccountEntry{label, fpid, sdkToken, encrypted, state: PENDING|CREATING|RUNNING|SUCCESS|FAILED|TRANSFERRED?, error, steps 摘要, uid?, furnaceLevel?}>`。
- `importAccounts(List<String> encryptedOrLines)`：逐行解析——加密串（RegistrationService.parseEncrypted）或 `fpid|sdkToken` 两段式；去重（fpid）；非法行报行号错误。
- 执行（daemon 单线程串行）：对每号——建 engine（EngineFactory 注入，测试替身）→ `BootstrapService.createRole(engine,...,serverId,roleName?)`（失败→该号 FAILED 记 error，继续）→ 循环 `runUntil(maxSteps)` + Sleeper 等待（每轮间隔 5s，直到 COMPLETED/不可继续；总时长上限 cfg.batchTimeoutMinutes 默认 120 防死循环）→ 目标达成后 `joinAlliance`（allianceName 空则跳）→ 号状态 SUCCESS（记 furnaceLevel/uid）→ engine 关闭（参照 SessionKeeper 的会话关闭方式；`WjdrEngine` 若有 close/disconnect 用之）。
- cancel：当前号自然结束（对齐注册批次 runner 语义）。
- 统计与文案：「开始批量起号：区服 X，目标大熔炉 Y 级」「批量处理结束：成功 N 个，失败 M 个」（对齐原版前端日志文案）。

### 2.3 `bootstrap/BootstrapReferral.java`（回流清单，新文件）

- 起号 SUCCESS 的号（含注册批次 SUCCESS 号的统一入口）写入 `data/bootstrap_referral.json`（原子写+bak，模式对齐 RegistrationStore）：`{fpid, sdkToken, encrypted, label, serverId, uid, furnaceLevel, batchId, bootstrappedAt, pulled:false}`。
- API：`listPending()` / `markPulled(fpids)`。**不直接写 VaultStore**（App→server 全量 sync 会覆盖服务端自建账号；回流由 App 拉取后并入 AccountStore 再 sync——M5 实现）。
- sdkToken 明文允许存于该文件（它就是回流数据本体，与 registration 持久化视图只存 encrypted 不同——此文件是凭据交付清单）；文件权限与 data 目录一致；日志/异常输出一律 mask。

### 2.4 `bootstrap/BootstrapApi.java` + 挂载（新文件 + 改 Main/VaultHttpApi 两个既有文件）

- `handle(fields)` action 分发：
  | action | 入参 | 出参 |
  |---|---|---|
  | `import` | lines[]（加密串或 fpid\|token） | 解析结果（成功清单/错误行） |
  | `batch-start` | serverId, targetFurnaceLevel?, allianceName?, roleName?, instantDiamond?, accounts[](fpid+sdkToken 或 encrypted) | 批次概要 |
  | `batch-status` | batchId | 批次全量（每号状态/步骤摘要/统计） |
  | `batch-cancel` | batchId | 取消结果 |
  | `batch-list` | limit? | 批次列表 |
  | `referral-list` | - | 待回流清单 |
  | `referral-pull` | fpids[] | 标记已拉取 |
  | `single-status` / `single-run-next` / `single-run-until` / `single-level-building` / `single-alliance` | fpid（从回流清单/批次内存表定位 engine；无在线 engine → error「该号不在线，起号会话未运行」） | BootstrapService 对应结果 |
- 校验：serverId 正整数；targetFurnaceLevel 1–9；accounts 1–100；错误统一 `{error:中文}`。
- Main.install + `/v1/vault/bootstrap` context（guard "POST","vaultBootstrap"），对齐 registration 挂载形态。
