# 行军队列战术手册——调度优先级·道具时机·反加速决策

> 版本 v1.0 · 2026-10-15 · 依据：玩家实战实证四条（§1）+ 守护盟友系统设计 v1.2 的模型推演
> 用途：人读战术手册，同时作为守护盟友（Guardian）自动化调度的策略规格。
> 关联：`design/守护盟友-自动驻防系统设计-20261015.md` §6.10（QueueGuard）

## 1. 机制事实（玩家实证，全部为本手册推理公理）

| # | 事实 | 战术含义 |
|---|---|---|
| F1 | **驻防（驻扎）同样占用行军队列** | 队列成本 = 去程 + 驻扎全程 + 回程；"打完仗"不等于"队列回血"，驻扎是最容易被忽视的占队状态 |
| F2 | **出征与返程均可使用加速道具或钻石加速** | 回程不是死时间——返程行军可压缩，"释队"是有手段的主动操作 |
| F3 | **双方各 6 队；敌方进攻与召回的行军时间均可推算** | 敌方队列占用周期可计算 → 我方道具使用可以精确到"需要压缩多少秒"，避免过量浪费 |
| F4 | **原地附近使用高级迁城 → 全部 6 队瞬间回城并恢复可用** | 存在"一键全释队"手段；多队列被困时，1 个迁城道具优于 N 个加速道具，经济最优 |

## 2. 决策公理序（v1.5，最高约束，先于一切战术规则）

```
第一（不可妥协）：驻防盟友成功——防御先于敌方攻击生效。
第二（次约束）  ：加速道具/钻石消耗最小化——同等防御效果的方案里选最省的。
第三（权重为零）：队列经济帐——采集停摆/行军中断/机会成本不进入任何决策。
```

由此推论：战争态进入与维持不看经济账（侦查骚扰导致采集停摆不是顾虑）；队列纪律
（保留池、hold-fire、迁城释队）的存在理由是**保住防御能力**，不是省钱；唯一仍在
计算的消耗是道具/钻石存量。

## 3. 队列状态模型与占用时长

```
队列状态：FREE（可用）→ OUT（去程）→ GARRISONED（驻扎，仍占队）→ RETURNING（回程，仍占队）→ FREE

单次驻防的队列占用 = 去程时长 + 驻扎时长 + 回程时长
其中：去程/回程可被加速压缩（F2）；驻扎只能靠撤防解除（且撤防后仍有回程）；
      全状态可被迁城一键归零（F4）。
```

推论：
- **驻扎是队列的"慢性占用"**：威胁清零后每多驻 1 分钟，就少 1 分钟的防御纵深。纪律：打完即撤（无后续威胁时）。
- **回程是"可压缩的死时间"**：召回后队列并非立即恢复——回程时长是敌方"召回→再攻"窗口的来源，压缩回程 = 直接压缩敌方的可乘之机（F2）。
- **迁城是"全局复位键"**：把 6 队的占用状态一次性清零（F4）。

## 4. 行军队列调度优先级

### 4.1 用途优先级（高 → 低）

| 级 | 用途 | 准入规则 |
|---|---|---|
| P0 | **已确认真攻的驻防**（敌已过介入点/坚持到末段/大军集结） | 可动用**保留队列**（6 队中的 2 队，任何情况下不为低优先级用途开放） |
| P1 | 高可信威胁的提前戒备驻防 | 普通队列 |
| P2 | 常规驻防响应（可信度未定的进攻） | 普通队列，且遵守 hold-fire：敌剩余 > 介入点（约 8s）前不发射 |
| P3 | 日常出征（采集/狩猎/游历/探险） | 普通队列；**P0/P1 需要时必须让位**（可召回，损失=单次采集收益） |
| P4 | 可选出征（多余兵力挂机采集等） | 仅在队列富余时；有威胁迹象时主动回收 |

### 4.2 队列健康红线（时刻自检）

1. **保留 2 队原则**：任何时刻，至少 2 个队列只对"已确认真攻"开放——日常与低可信威胁最多占用 4 队。
2. **驻扎即负债**：每个 GARRISONED 队列都要问"这个目标还有威胁吗？"——没有就撤。
3. **回程即倒计时**：每个 RETURNING 队列都记 etaHome（到家时刻）；敌方可乘窗口 = 召回发起到我方队列 FREE。
4. **佯攻零供给**：低可信攻击方（有召回前科）在介入点之前，一队不给。

## 5. 加速道具使用时机（F2/F3 → 节制原则）

### 5.1 三个合法用途

| 用途 | 场景 | 档位选择 |
|---|---|---|
| A. 卡秒秒进 | 敌加速/临近到达，我方去程需压缩至先于敌落地 | 差距大（>50% 剩余）用高档（50%），差距小（≤20%）用低档（25%）；**逐发使用、每发读真实剩余时间**，防过量 |
| B. 释队压缩 | 队列在回程，需提前到家腾队迎新威胁 | 同上；先算"需要提前多少秒"再选档 |
| C. 抢救 | 钻石直接加速（无道具时） | 仅 P0 场景；设日预算帽防失控 |

### 5.2 节制三问（每次用道具前，F3 推算使这三问可算；v1.5 按公理序重述）

1. **能不能等？** 敌到达 ETA − 我自然就绪时间 ≥ 0 → 不用道具，等（等待不消耗任何资源）。
2. **要压多少？** need = 我方就绪时间 − (敌 ETA − 安全提前量)。按 need 选档，宁可两发低档精准达标，不要一发高档过量——**公理序第二优先的直接执行：同等防御效果下消耗最小**。
3. **有没有更省的等效方案？** 单队困住用回程加速、多队困住用迁城（§6.2 公式）、都不够才钻石——消耗阶梯走到底再放弃。

（v1.5 注：道具节制的唯一理由是公理序第二优先"消耗最小化"，与目标值多少钱无关——
**任何盟友驻防都无条件执行**，只存在"怎么用最省"的问题，不存在"值不值得防"的问题。）

反例（多耗）：敌 ETA 还有 60s，我回程队列 etaHome 55s → 等待即可，却习惯性秒回 = 白白多耗道具。

## 6. 高级迁城的使用时机（F4 → 全局释队，消耗品最优解）

### 6.1 触发条件（同时满足才用）

```
① 困境确认：队列全忙 且 忙碌队列中 ≥3 个无法低成本快速释放
   （典型形态：全部 RETURNING / 大量 GARRISONED 且威胁已清 / 混合态 etaHome 都很远）
② 威胁确认：敌方新进攻正在加速来袭（有明确的 P0 需求），且等待+单队列加速都不够快
③ 位置无损：可迁至原地附近（不破坏资源加成/联盟布局/战略位置）
```

### 6.2 消耗对比公式（公理序第二优先：同等防御效果下消耗最小）

```
迁城净省 = Σ(各被困队列单独释放所需道具数) − 1（迁城道具）
判定：Σ ≥ 2 即迁城占优；Σ = 1 时等价（看哪种道具库存更稀缺）；Σ = 0 不会触发（6.1①不满足）
（队列停摆本身不进入公式——公理序第三：经济帐权重为零）
```

### 6.3 操作要点与注意

- **原地附近迁**：位置偏移最小化，避免破坏采集加成布局与联盟防区。
- 迁城前的瞬间自检：确认没有**我方正在进行的去程驻防**会因迁城被迫中断造成损失（若有，先让它落地再迁或改用单队列释队）。
- 迁城 CD / 库存量纳入预备知识（自动化需读道具库存与 CD 状态）。
- 迁城后 6 队 FREE，**立即按 §4.1 重新分配**——迁城释放的队列优先给 P0，不要顺手派去采集。

## 7. 面对敌方加速进攻的决策原则（总决策树）

```
敌进攻出现（推算其到达 ETA 与召回习惯, F3）
 │
 ├─ 1 威胁判定：佯攻前科/兵力/是否坚持 → 佯攻倾向高？
 │    └ 是 → hold-fire：介入点(≈8s 剩余)前不投队列；其提前召回 = 我零成本
 │
 ├─ 2 队列盘点：FREE 几队？OUT/GARRISONED/RETURNING 各几队、etaHome 各多少？
 │
 ├─ 3 时间差：need = 我方最速防御就绪 − (敌 ETA − 安全提前 0.5~1s)
 │
 └─ 4 资源阶梯（按成本从零到高）：
      L0 有 FREE 队 → 直接秒进卡秒（仅消耗卡秒所需道具, §5.1A）
      L1 队忙但某队 etaHome ≤ 就绪时限 → 自然等待（零消耗）
      L2 单个队困住时限 → 该队回程加速（1~2 个加速, §5.1B）
      L3 多队被困/全返程/无危险驻扎满员（§6.1）→ 高级迁城一键全释（1 道具）★
      L4 迁城不可用（CD/无货）→ 逐队列 L2（成本上升，逐队评估节制三问）
      L5 仍无解 → 弃最低价值目标并告警（人工/联盟协调）
```

### 7.1 三条总原则（浓缩，v1.5 按公理序重述）

1. **驻防无条件，消耗讲阶梯**：盟友要防就一定防（公理第一），方案按消耗从零到高走：能推算就不赌、能等待就不花、能集中就不零散（公理第二）。敌方时间可算（F3）是节制的前提，迁城（F4）是"集中释放"的最优形态。
2. **队列是战略资源，道具是战术资源**：队列纪律（保留池、hold-fire、打完即撤）保护的是**防御能力**（公理第一），不是采集收入（公理第三：经济帐权重为零）；道具只解决"时间差"。
3. **敌方加速 = 敌方投入**：对手每次加速都在消耗自己的道具存量；我方最优反应不是对等加速，而是用消耗阶梯上最低的一档（等/单道具/一次迁城）让他的投入落空。

## 9. 战争状态（ wartime ）——队列管制的最高形态

> 对应系统设计 §6.11（WarState）。当敌方进攻盟友被**确认**（全程加速秒级完成进攻 /
> 多路并发 / 反复侦查试探的系统性牵制），队列政策从"保留 2 队"升级为"**6 队全部
> 为驻防与支援预留**"，采集、狩猎等一切非战斗行为暂停。

### 9.1 进入战争的判定（v1.4：侦查即入，召回先于开战）

| 级别 | 信号 | 效果 |
|---|---|---|
| **H0（最优先）** | **任意敌方玩家的侦查行军指向盟友** | 立即战争态 + 全部采集中队列即刻召回（免费召回先于开战——开战后召回必须烧加速道具，道具成本远高于提前中断采集的少量资源损失） |
| H1 | 盟友城池被攻落地（战斗结算确认） | 立即战争态 |
| H2 | ≥2 路进攻并发指向盟友 | 立即战争态 |
| H3 | 极限压缩攻击进行中（全程加速者来袭） | 立即战争态 |
| H4 | 30min 内 ≥5 次佯攻（系统性牵制） | 立即战争态 |
| 软评分 | 新进攻 +30 / 战斗 +40 / 佯攻 +10 / 联盟战争通知 +15（10min 半衰） | ≥25 只到预警级（停可选出征、采集限近郊） |
| 人工 | 强制战争态 / 解除 | 最高优先级 |

**友军与自家小号的侦查不算**（盟友名单过滤 + 白名单）；H0 无法识别时自动降级为软信号
（战争态改由 H1–H4 触发，功能不残废）。

### 9.2 战争态下的队列纪律

1. **全部 6 队只做三件事**：迎击已确认真攻 → 高可信戒备 → 被攻目标增援补驻。
2. **非战斗一律暂停**：采集/狩猎/游历/探险/宴会/运宝……发射闸与队列准入闸双闸锁死；
   已在途的立即召回（免费）。战斗支援类不占队列的（开盾、治疗）照常。
3. **空队列就是战斗预备队**：闲着也不派活——"所有队列都应为驻防预留，不得挪作他用"。
4. 战时全忙仍走 §6 决策树（等待 → 单队加速 → 迁城 → 钻石），迁城权重上升。

### 9.3 退出恢复（v1.4：全敌静默 30 分钟，或全敌开盾）

- **多敌规则**：敌情板逐个敌人跟踪（谁在侦查/进攻、最近动作时刻、是否开盾）。
  **只要还有一个敌人未静默满 30 分钟，就不退出**——第 29 分钟冒出的第二个敌人，
  其静默计时从零起算。撤盾 = 恢复攻击能力 = 新信号，重置计时。
- **开盾即非威胁**：全部敌方威胁源都开着护盾 → 直接退出（开盾者无攻击能力）。
- 退出后：任务闸重开，当日被暂停任务自动补跑；队列池还原为"保留 2 队"。
- 人工通道随时可强制退出；战争态持续超 2 小时提醒一次（敌情板上可直接指认骚扰者）。
- 误入战争态的代价只剩道具机会性消耗与指挥注意力（公理第二范畴；采集停摆按公理第三
  不计）；漏入的代价是盟友裸攻 + 战后召回烧道具（公理第一失守）——不对称裁决：**宁可错入**。
