## 1. 背景与范围

「起号+注册」模块需要服务端直连游戏官方 FunSDK passport（世纪游戏 campfiregames），实现四个通道：
**发短信验证码（sms_send）、验证码登录（sms_login）、游客快速注册（guest_register）、实名认证（real_name）**。
本期（M1）只做**纯库 + 单测**：不做网络路由挂载、不接 HTTP API（后续 M3 挂）、不真实外呼（单测全部用注入的假 transport）。

### 2.2 DeviceProfile.java
一次性设备指纹（注册/登录时每个新号独立生成）：
- 字段：`guid/originGuid/androidId`（同一 32 位小写 hex 随机）、`distinctId`（32 位小写 hex 随机）、`device="meizu MEIZU 18 Pro"`、`deviceOs="android"`、`countryCode="CN"`、`lan="zh_cn"`、`version="1.16.12"`、`packageTag="App_android_8_funplus"`、`adSource="funplus"`。
- `random()` 静态工厂；`seeded(byte[] seed)` 供单测生成确定性实例。
- `toLoginProfile()`：输出 `{account:"", device, device_os, country_code, distinct_id, lan, version, package_tag, ad_source, device_id}` 的 `Map<String,String>`（account 由调用方填 fpid）。

### 2.3 PassportClient.java
核心客户端，构造注入 `PassportConfig` 与 `Transport`：
```java
public interface Transport { String post(String url, Map<String,String> headers, Map<String,String> form); }
```
（Transport 作为 PassportClient 的嵌套接口；生产实现 `HttpUrlConnectionTransport` 用 `HttpURLConnection`，`application/x-www-form-urlencoded`，UTF-8，10s 连接/15s 读超时；单测不碰它。）

公共方法 `PassportResult call(String serviceName, Map<String,String> businessParams, DeviceProfile profile)`：
1. 组 form（**LinkedHashMap 保持插入顺序**）：`method=serviceName`、`game_id`、`service_name=serviceName`、`l`、`game_version`、`domain=funsdk`、`sdk_version`、`origin_address`；若有 profile：`guid/origin_guid/android_id=profile.guid`；再合并 businessParams（值 null/blank 跳过）。
2. 签名：`Authorization: FP <gameId>:base64(hex(HMAC-SHA256(按 key 字典序拼 k=v&…, gameKey)))`——与 `WechatQrLogin.signPassportJava` 逐字同构（含 base64 的是 hex 字符串的 bytes）。
3. `cg-seid` 头：config.cgSeid 非空取之；否则 `md5hex(fpcsSource + "7CPsU5puEk")`；fpcsSource 也空则不发该头。
4. Transport 返回 JSON 文本 → 解析为 `PassportResult`。

`PassportResult`（嵌套类）：`status`（HTTP 层成功且 JSON 可解析即 true）、`data`（JSONObject：root.data，无则 root 本身）、`raw`（原文，toString 时截断 300 字符）、`fpid()/sessionKey()`（从 data 或 data.login_profile 两层按序取 `fpid|account|fp_id` / `session_key|sdkToken|sdk_token` 第一个非空）、`errorText()`（按序取 `error|error_msg|message`）。
解析失败抛 `PassportException`（RuntimeException 子类，消息含截断原文，**不得包含 Authorization 头**）。

四个业务方法（全部经 `call`）：
- `sendSms(String mobile, String countryCode /*默认"86"*/, DeviceProfile profile)`：business=`{mobile, length:"4", fpid:"", session_key:""}` + `country_code`。**60 秒/号冷却**：`86:纯数字mobile` 为 key 的内存表（ConcurrentHashMap），冷却期内再调抛 `IllegalArgumentException("验证码已发送，请 N 秒后再试")`；发送异常时释放预约（对齐原版 reserveSmsSend/cancelSmsSend 语义）。
- `smsLogin(String mobile, String code, DeviceProfile profile)`：business=`{mobile, code, session_key:"", android_id:profile.androidId, install_channelid:"funplus"}`。
- `guestRegister(DeviceProfile profile)`：business 仅公共参数（无额外字段）。
- `realName(String fpid, String sessionKey, String name, String idCard)`：business=`{fpid, session_key, name, id_card}`；调用前本地校验：18 位身份证格式（17 数字 + 数字/X），不合法抛 `IllegalArgumentException("身份证号格式不正确")`；姓名 blank 抛 `IllegalArgumentException("请输入姓名")`。

### 2.4 PassportException.java
独立文件，RuntimeException 子类。

### 2.5 PassportIds.java（工具）
- `hmacSha256Hex/toHex/md5Hex/base64`（静态工具，供 Client 与单测复用）。
- `mask(String)`：≤6 全 `***`，否则 `前3***后3`。
- `normalizeMobile(String)`：去非数字。
- `isValidIdCard(String)`：18 位校验（含结尾 X/x；本期不做校验码加权验算，注释说明）。

## 3. 单测要求（JUnit 4，`vault-server/src/test/java/com/carlos/vaultserver/passport/`）

1. `PassportClientTest`：
   - 表单组装：固定 config + 固定 DeviceProfile（seeded）+ fake transport 捕获 form —— 断言字段、顺序（method 首位）、guid==androidId==originGuid、blank 业务值被剔除；
   - 签名：对捕获 form 独立复算签名并断言与请求头一致；再断言与 `WechatQrLogin.signPassportJava` 对同一参数集结果一致（工程内互证）；
   - cg-seid：fpcsSource 路径（断言=md5(src+"7CPsU5puEk")）与显式 cgSeid 优先；
   - 响应解析：`{data:{fpid,session_key}}`、`{data:{login_profile:{fpid,session_key}}}`、无 data 回退 root、error 文本提取、非法 JSON 抛 PassportException 且消息不含 Authorization；
   - 60s 冷却：同号第二次 sendSms 抛错且消息含剩余秒；smsLogin 不受冷却影响；不同号互不影响；transport 抛异常后同号可立即重试（预约已释放）；
   - realName：格式校验三条（缺姓名/坏身份证/正常通过）。
2. `DeviceProfileTest`：random 的 hex 规范与 guid 三字段一致；seeded 确定性；toLoginProfile 键集。
3. `PassportConfigTest`：defaults、覆盖、maskedSummary 掩码。
