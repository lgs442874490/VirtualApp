# 验收用例：藏宝阁-移民（自由移民）1:1 复刻（2026-11-06）

> 分支 `add/migrant-1to1-20261106-2058` · 依据 `docs/requirements/移民功能-需求文档-20261106.md` §7
> 环境：vault-server（新版）+ App（T3 正式包）+ **专用测试角色**（承担真实退盟/召回/迁移）
> 标注：⚠ = 消耗真实资产或不可逆

## A. 门控与入口

| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-M01 | 非 T3 账号（T1/T2）打开工具箱 | 不出现「移民」卡片（`FeatureGate.visible(IMMIGRATION)=false`） |
| TC-M02 | T3 账号 + 服务器模式打开工具箱 | 出现「移民」卡片，副题「自由移民 · 资格预检、边界任务与毫秒级抢位」；点击进入工作区 |
| TC-M03 | T3 账号 + 非服务器模式（本地模式）打开工具箱 | 不出现「移民」卡片（服务端任务型模块前置） |
| TC-M04 | 旧服务端（无 `/v1/vault/migrant`） | 进入页面后接口失败有中文提示，不崩溃 |

## B. 概览与数据

| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-M05 | 角色在线，活动处于自由移民期 | 状态标签 `自由移民中`(success)；倒计时「自由移民剩余 X天 X时 X分」；进度条游标落在「自由移民」段 |
| TC-M06 | 活动未开放 | 标签 `活动未开放`(info)；顶部出现「移民活动当前未开放」提示；仍允许创建任务 |
| TC-M07 | 角色离线 | 目标王国下拉与操作按钮禁用；数据区显示 `-`；撤退弹窗提供「上线」按钮 |
| TC-M08 | 选目标王国 | 展示王国详情：王国状态（强盛/普通）、已用名额、普通移民、实力限制（`≤N` 千分位，或 `未知（档位 x）`） |

## C. 资格预检

| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-M09 | 离线角色点「资格预检」 | 阻断项含离线原因；「提前测试/创建/批量」保持禁用 |
| TC-M10 | 在线角色（在联盟）点预检 | checks 列出「联盟」等阻断项且 `ready=false` |
| TC-M11 | 在线角色（已退盟/未入盟）点预检 | `ready=true`；显示授权书 `owned / required` 与剩余名额 |
| TC-M12 | 目标王国战力超限 | checks 出现战力上限阻断项，`ready=false` |

## D. 任务创建与调度

| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-M13 | 创建单个任务（提前量 0） | 返回 job；大盘出现 WAITING 行；倒计时「距开放 X」 |
| TC-M14 | 提前量输入 150 | 输入框上限 100（服务端亦钳位 [0,100]） |
| TC-M15 | 同角色再建一个任务 | 被拒并给出中文原因；大盘不新增 |
| TC-M16 | 批量创建 ≥2 账号（含 1 个离线/不同赛区） | `已创建 n / m`；失败账号逐条列原因，不影响成功账号 |
| TC-M17 | WAITING 任务点「取消」 | 二次确认后 CANCELLED；不再上号、不发射；转入历史 |
| TC-M18 ⚠ | 任务到 `freedom_start-15min` | 服务端自动登录该角色，执行退盟/召回；大盘显示「召回中」→「已安排回城」；`exit_alliance_message` 显示「已自动退出」 |
| TC-M19 ⚠ | 回城预计晚于开放前 2 分钟且勾选加速 | 依次消耗二阶→一阶加速器；`加速器 n 二阶 / n 一阶 / n 钻石` 计数递增 |
| TC-M20 ⚠ | 背包无召回道具且勾选钻石兜底 | 首次召回返回 `requires_diamond=true`，二次确认后以 `mode=diamond` 成功（消耗 800 钻）；每任务上限 10 个 |
| TC-M21 ⚠ | 到点发射 | attempts 首发 `sent_at_millis - freedom_start_millis ∈ [-advance, +50]`；`clock_source=role_clock` |
| TC-M22 ⚠ | 迁移成功 | 任务 SUCCEEDED；`reconciled_kid = target_kid`；历史行显示「重登王国 K{目标}」 |
| TC-M23 | 发射后无响应/断线 | 任务 UNKNOWN；「重新核验」可触发重登对账并刷新结论 |
| TC-M24 | 重启 vault-server | `GET jobs` 任务仍在；WAITING/PREPARING 按剩余时间恢复调度；已过窗口无结果转 UNKNOWN |

## E. 撤退详情

| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-M25 | 打开撤退详情（未开自动召回） | 顶部警告「该任务未开启「开放前自动收回外出部队」，请在开放前自行保证部队全部回城」 |
| TC-M26 | 行军列表 | 每支显示类型、坐标 `(x, y)`、`到达时间 · 剩余 X`；集结行军显示「集结行军不支持召回」 |
| TC-M27 ⚠ | 单支行军部队召回 | 消耗 1 个召回道具；提示「需要「X」道具 1 个（背包 n）」 |
| TC-M28 | 采集等工作状态部队召回 | 提示「免费撤回（停工作）」，不消耗道具 |

## F. 请求审计

| 用例 | 步骤 | 期望 |
|---|---|---|
| TC-M29 | 打开请求审计 | 标题「自由移民 · 请求审计」；显示 N 次迁入请求、状态标签、最终响应码 |
| TC-M30 | 时间轴 | 10 项时间（freedomStart/createdAt/armedAt/sentAt/firstSentAt/firstServerNow/lastSentAt/firstResponse/lastResponse/finishedAt）；逐项标注「开放前/后 N ms」「距首次请求 +N ms」 |
| TC-M31 | 对时统计 | 「全部 n 次请求已对时」/「n/m 次已对时」/「全部 n 次请求未对时」按实际渲染 |
