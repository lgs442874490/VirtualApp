# 守护盟友 P4/P6/P7 完善 + 标定/战报码表（2026-10-22）

依据 `守护盟友-自动驻防系统设计-20261015.md`、`守护盟友-开发计划-20261015.md`、`守护盟友-会话交接-20261017.md`。本轮完成交接文档「遗留 1/5」与开发计划 P4/P6/P7。

## 一、距离分档标定 D（遗留 #5）
- `GuardianCalib`：按 `fpid:kid` 存 `calib.{near,mid,far,single}`（D 秒均值 + 样本数）。
- 距离分档阈值可配 `dist_near`（默认 20 格）、`dist_mid`（默认 60 格），否则 far。
- 使用点：①发射时机 `fireAt = 敌ETA − D档 − Δ`；②加速介入线 `clamp(D/2,4,20)`；③EndgameGuard 兜底。
- 校准：每次驻防发射成功采样实测 D（服务器时钟域，endtime−发射时刻），EWMA α=0.3；缺档回退 single→38s。
- 旧单值标定（guardian_calib.txt）自动迁移进 single 桶。

## 二、防守战报码表（遗留 #1/#4）
- `GuardReportCodes`：默认表 4/5=win、6/7/8=loss（来源=进攻战报映射，防守语义待校准）；支持 `report_codes` JSON 覆盖（roles/second/by_first）。
- 未收录 second_type（如实测防守样本=1）：**不判成败、不撤防**，写 `GUARD_REPORT_UNKNOWN first=.. second=.. raw=..` 并按 first:second 去重计数入 FnParams 待校准列表（≤20）。
- 下次防守胜/败各采一例对照游戏内战报，用 `report_codes` 覆盖即完成校准。

## 三、P6 常驻戒备（EXTREME 惯犯）
- `GuardianHold`：`fpid:kid → targetUid → holdUntil` 账本；EXTREME 锁存或本轮压缩≥3 时武装；威胁在途不超时/新威胁在位承接。
- 参数 `hold_garrison_min`（默认关/0）：0=完全保持原「战报出即撤防」；>0=保留 15/30/60/120 分钟。
- 三条撤防路径（repatriate/repatriateDelayed/sweepOrphans）统一经 shouldHold 拦截。

## 四、P4 预驻防
- `GuardianPreGarrison`：H3 极限惯犯（含侦查）或 H2 ≥2 路合格并发 → 提前向受威胁盟友城派驻；同目标 10 分钟冷却；默认关（`pre_garrison`）。
- 门控：冷却→已驻防→反应式执行中让位→恒留 1 队给反应式；队列满走既有 2878 仲裁；无威胁滞留 10 分钟自动清扫撤回。
- 状态行：`🛡常驻戒备中（剩余Xm）`、`🚀预驻防 → 盟友(坐标)`。

## 五、P7 WarState 完整版 + server 对等
- App `WarState`/`ThreatBoard`：H0 侦查即入 / H1 战斗确认 / H2 多路并发 / H3 极限压缩 / H4 佯攻潮（5 次/30min）；软评分（新进攻+30/战斗+40/佯攻+10/联盟战争通知+15，10min 半衰）；ALERT→WARTIME；退出=全敌静默 ≥ `quiet_exit`（默认 30min）或全敌开盾（`shield_exit`）；人工强制/解除；E1-E6 动作（停采集/限近郊/停可选出征/队列让位/通知摘要）；`war.allowlist` 任务白名单。
- 参数 `p:war.*`（阈值/静默分钟/开盾退出/allowlist…）热载。
- **vault-server 对等**（开发计划裁决①）：`ServerWarState` 同源编译 `WarState/ThreatBoard`（build.gradle 加入），SessionKeeper 推送→判定；`RoundRunner/ModularRoundRunner` 逐任务闸；`RoundScheduler` 战时让位；`/status`、`/accounts` 暴露 warState 摘要；`war.allowlist` 缺省对等 App 默认。
- 兼容：无威胁=非战时（原 lite 语义「有威胁即战时」在无完整信号时仍按有威胁判定），推送数据缺失自动降级不抛错。
