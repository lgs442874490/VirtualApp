# 需求文档：藏宝阁-移民（自由移民）1:1 复刻

> 2026-11-06 · 状态：已确认（用户逐项通过）· 分支 `add/migrant-1to1-20261106-2058`
> 唯一权威基准：网页版 `http://111.228.32.189:8888/`（`assets/MigrantWorkspace-C_ZVt8cF.js`）
> 原版反编译：`ZCodeProject/wjdr-review/src-tool/com/wjdr/tool/modules/migrant/`

## 1. 背景与目标

原版网页版「藏宝阁」顶级导航下有「移民」子模块（自由移民：移民资格与边界任务）。本仓库 App 与 vault-server 此前**无任何移民实现**（`FeatureGate.IMMIGRATION` 为 implemented=false）。

目标：按「编队」既有复刻模式，**App + 服务端双端** 1:1 复刻：服务端实现全部接口与到点毫秒级抢位执行引擎；App 以原生 UI 还原网页版工作区信息架构、文案与行为。

## 2. 范围与非目标

**范围**
- 服务端：`/v1/vault/migrant`（14 个 action）+ 任务持久化 + 准备/抢位/对账引擎 + 调度
- App：工具箱「移民」入口 + 移民工作区（含 3 个弹窗）
- `FeatureGate.IMMIGRATION` → implemented=true，维持 TIER_PREMIUM
- 真机实测：专用测试角色真迁移全链路验收

**非目标**
- 不复刻「藏宝阁」一级导航分组（仅移民单项；其余藏宝阁模块按「未开发不显示」保持隐藏）
- 不做迁城/首占等兄弟模块
- 不做像素级 UI 度量复刻（App 原生组件，遵循 `design/UI规范.md`）
- 不改动用户已有的未提交改动

## 3. 用户与场景

- **用户**：T3 高级会员，持多角色账号池，需在自由移民窗口开放的瞬间把角色迁入目标王国抢名额。
- **单角色发车**：选目标王国 → 资格预检 → 勾选自动准备 → 创建边界任务 → 服务端开放前 15 分钟上号退盟/召回/加速 → 开放时刻毫秒级提交 → 大盘看就绪态与倒计时 → 审计弹窗看请求明细。
- **批量发车**：多选账号 + 统一目标王国，一次下发；失败账号单独列原因。
- **兜底干预**：撤退详情手动单支/全部召回（道具或 800 钻）；异常任务重新核验或取消。

## 4. 功能需求

### S 组：服务端

**S1 serverClock** —— 复用既有 `GameServerClock`（已完成，不重写）
- 校准源：登录响应 / `notify_game_init` / 心跳；单调外推；`waitUntil` >100ms sleep、≤100ms parkNanos
- 上报 `clock_source`：`role_clock`（已同步）/`role_clock_unsynced`/`host_wall_clock`

**S2 数据模型**：任务（字段见实施契约 §4）+ attempts（对时标记/阶段/结果/请求响应原文）；持久化 `data/migrant.json`（原子写 + .bak）

**S3 14 个 action**（字段与网页版 1:1）：`accounts` / `overview` / `precheck` / `test-early` / `create` / `bulk` / `jobs` / `cancel` / `recheck` / `marches` / `recall` / `attempts` / `login` + 越权校验

**S4 执行引擎**
- 准备窗口 `freedom_start-15min` 自动上号：退盟、召回在外部队（行军道具/采集免费撤回）、回城晚于 `-2min` 用加速器（二阶→一阶）、背包不足且允许时钻石购买（召回 800 钻 / 加速器 400 钻，每任务上限 10 个）
- 抢位：`waitUntil(freedom_start - advance_millis)` 后 50ms 节拍、最多 200 次、停止信号即时中断；attempts 记录阶段（BURST/FOLLOW_UP/FALLBACK）
- 判定：`notify_migrant_first_login` 为候选成功信号；以重登读当前王国对账（90s 窗口）为准
- `advance_millis ∈ [0,100]`；服务重启按剩余时间恢复调度

**协议（已实证）**：`req_migrant_get_kingdom_list` / `req_migrant_get_kingdom_info` / `req_migrant_migrate` / `req_migrant_first_login`；通知 `notify_migrant_init` / `notify_migrant_first_login` / `notify_server_time`

### A 组：App

- A1 入口：工具箱「移民」单项（T3 + 服务器模式），门控放开
- A2 工作区：头部 / 概览条（服务器时间 + 三阶段进度条展望3天·邀请2天·自由移民2天 + 倒计时）/ 数据行（当前王国/期号/目标王国/授权书/剩余名额）/ 任务表单（王国下拉+详情、预检、提前测试、创建、批量、提前量、4 复选框级联禁用）/ 资格结果面板
- A3 任务大盘：范围切换 + 异常筛选 + 就绪 chip + 7 列任务行 + 空态双文案
- A4 撤退详情弹窗 / A5 请求审计弹窗 / A6 批量创建弹窗
- A7 刷新：前台 ≤2s 轮询、fallback 30s、可见性变化刷新、倒计时每秒本地 tick

## 5. 非功能

- N1 抢位精度：50ms 节拍在服务器时钟基准执行；App 倒计时秒级
- N2 多角色并发：各任务独立角色会话线程，不占全局锁
- N3 持久化：任务与 attempts 落盘，重启不丢
- N4 可观测：每次尝试留痕；危险操作全留档；不落 token
- N5 安全：危险操作二次确认；钻石消耗每任务上限 10
- N6 兼容：不引入新第三方依赖

## 6. 异常与边界

E1 离线→表单禁用+上线按钮；E2 活动未开放→提示标签但允许提前创建；E3 预检不通过→阻断项逐条+操作禁用；E4 时钟未同步→异常筛选+发射前回退墙钟并标记；E5 准备失败→异常标签+窗口内重试不中断；E6 发射无响应→UNKNOWN + recheck；E7 越界→advance 钳位 [0,100]、march_id=0 表全部、不存在 job/role→404 语义；E8 重复创建→同角色 active 任务拒绝/批量计入 failed；E9 200 次耗尽→REJECTED + attempts 全量可查

## 7. 验收标准

V1 预检（离线阻断 / 在线 ready=true）；V2 时序（`freedom_start-15min` 准备、首发偏差 ≤ advance+50ms）；V3 真迁移成功→SUCCEEDED 且 `reconciled_kid`=目标王国；V4 召回（单支真实消耗道具 / 背包 0 走 800 钻 / 集结不可召回）；V5 批量（≥2 账号，1 个被拒，created/failed 各自正确）；V6 取消→CANCELLED 不再上号；V7 门控（非 T3 不可见）；V8 重启恢复；V9 文案逐条对照一致
