|---|---|
| 未预约巨熊场次 | 该联盟未预约或数据未同步；需游戏内预约 |
| 未取到预约数据 | `notify_alliance_trap_update` 未到达；`req_alliance_trap_info` 只读查询失败 |

| 发起集结未成功（码5204） | 场次未开/准备档过长/队列不足 |
| 剩余时间不足准备档 | 窗口开始较晚，默认 620s 档来不及，可降 prepare_time_index |
| 已发车（幂等） | 本场已发过，不会重复发 |
