## 3. 已知问题与限制

### 3.1 master 基线测试红例 = 已知时钟 flake（已建 task-7）
- 用例：`CaptureTasksTest.calendar_familyNameAndText`（`vault-server/src/test/java/com/carlos/vaultserver/CaptureTasksTest.java:99-120`）
- 根因：`CaptureTasks.captureCalendar` 按北京时间判断 begin 是否“今天”，测试用 `now+3600s` 且断言恒含“今日开启”；**23:00–24:00 运行必失败**（跨日变“明日 HH:mm 开始”）。主工作区分支与 master 共用该测试/逻辑，与本 T5 改动无关。
- 处置：已建 task-7（test-only 修复，等 T6 后做）；全量测试在 0 点后/修复后应恢复全绿。

### 3.2 app 覆盖率（第二梯队）
- AGP 7.2 单测覆盖率 exec 路径可能为 `app/build/outputs/unit_test_code_coverage/debugUnitTest/testDebugUnitTest.exec`（非 `build/jacoco/*.exec`）；本次时间盒内未完成实跑验证。
- 决策：回退 `testCoverageEnabled` 与 app jacoco 配置；保留 test-retry。第二梯队再用“先跑 `:app:testDebugUnitTest` → 实查 exec 路径 → 对 XML `<counter type="LINE">` 非 0 验收”的方式落地。

### 3.3 离线/联网需求
- vault-server 新插件（spotbugs/retry/findsecbugs/jacoco agent）首次配置需联网 Plugin Portal + mavenCentral；缓存后 `--offline` 可用。
- root versions 插件同理（Plugin Portal）。
- 建议 CI：预置 Gradle 用户目录缓存，或提供 init-script 私服镜像，并在流水线记录“首次联网/后续离线”策略。
