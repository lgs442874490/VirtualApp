### 4.2 与原版 Web 版行为差异（验收基线，均已在代码注释声明）

除《测试用例》附录 A 的 12 项已声明差异（D1 直领不依赖推送 / D2 新增 DEGRADED / D3 behemoth 原生自动上车+bear 仅预约 / D4 钓鱼仅领奖 / D5 乔伊乱斗裁剪 / D6 采集一次性 / D7 护盾裁剪 / D8 竞技场无对手过滤 / D9 一次性执行语义 / D10 进阶工具规划中 / D11 自研 HMAC 授权 / D12 错误码分级）外，本次测试补充确认：

- 结果分类口径：本作 CLAIMED≈原版 SUCCESS（**必须有奖励证据字段**，修复原版"无异常即成功"）、SKIPPED≈原版合理跳过、ERROR≈原版 FAILED、SESSION_CLOSED 对应原版同名 failureCategory（唯一可重试）；
- `GameMessage.content` 默认为空 map（非 null）且 `code` 缺失按 0 处理——因此 `ExecUtil.ok()` 单独不能作为成功证据，任务层的证据字段+DEGRADED 兜底是必要设计（TC 通用判定已覆盖）；
- 活跃度档位 40/80/120/160/215/270/325、每日任务 21 个 quest_id、邮件单批 100 封、投壶 15 秒结算+满分 4650、免费招募 5 次/日、配兵 40/30/30（=原版 4:3:3）、XOR 默认密钥 `4b5eea17`、心跳 3s/60s、重连退避 8s→300s、顶号探测 30 分钟、时间窗默认 5-9 点——**均与原版数值一致（JVM/代码核对）**。

## 五、未覆盖项（需真实游戏环境，建议真机+有效 token 人工执行）

1. **50 项功能的协议执行与领取**（TC-F01~F50 的执行环节）：需真实 token 登录游戏服务器。协议正确性已由 schema/编解码往返测试与「协议流逐行移植自网页版」的代码审查覆盖，但领取结果、错误码分级、活动窗口门控的实际服务器响应未验证。
2. **常驻在线运行时行为**（TC-S04/S05/S06/S07/S08）：真实登录/心跳节拍/断线退避/顶号三档/code=26 停机。开关链路与策略落盘已验证；状态机常量与原版核对一致。
3. **推送唤醒/联盟互助/反应式开盾运行时**（TC-S09/S11/S13/S14）：需游戏服务器真实推送（或通知注入）。映射表、冷却、兜底轮询常量已经代码核对；模拟器未配置通知使用权注入链路。
4. **容器能力**（TC-P16 及向导①克隆②首开下载③基线）：模拟器无游戏 APK（com.gof.china 未克隆）。向导自动弹出行为已验证。
5. **TC-P06/P07/P08**（永久码激活、票据篡改 TAMPERED、离线 3 天宽限）：激活主链路已由月卡码验证；三态锁定页逻辑经代码审查（LicenseManager.computeState 判定顺序），未逐态实操。
6. **自动日常整轮真实调度**（TC-S01/S02 的随机时刻分布）：nextRunInWindow 为私有方法且依赖系统时钟，未做时间注入；逻辑分支经代码审查，wake 闹钟排入已实测。
7. **模板/同步、roleConfig 三层迁移、free_shield→battle_shield 改名**（TC-C03/C04/C07）：SharedPreferences 层逻辑经代码审查，未在模拟器逐项构造旧数据验证。
8. **游戏内多角色互踢（code=46）与切号快照恢复**：需容器+游戏环境。

## 六、回归结论

- **配置项全部真实生效**：功能开关（角色级 JSON 落库）、默认值矩阵（32/18）、时间窗（UI+prefs 双向）、顶号策略、常驻开关、授权票据——均有落盘证据与 UI 联动证据。
- **策略逻辑与原版一致**：签名（登录 SHA-1 与授权 HMAC 黄金向量）、协议编解码（sproto/XOR/RC4/帧）、调度与退避常量、活跃度/任务/商店/科技目录数据——逐字节或逐数值对齐原版；已声明的 12 项差异均为有意裁剪且在 UI 标注（「待开放/规划中/下一版」）。
- **无回归**：102 个 JVM 用例全绿；构建通过；模拟器 14 组 UI 用例全过；开发者的既有数据在测试后已完整还原。
