systemctl is-active vault-server

## 4. 验证（三层，逐层通过再继续）

### 4.1 服务与启动日志

```bash
ssh gz 'systemctl is-active vault-server; journalctl -u vault-server -n 60 --no-pager | tail -40'
```

**必须出现**（本次新增能力）：
```
移民任务恢复完成：共 N 个任务，活跃 M 个
移民调度器已启动：1s 扫描（准备分轮/发射/对账分轮/延迟复核）
移民模块：已启动（任务 N 个）
HTTP API 已启动：0.0.0.0:8790
```

**不得出现**：`未知的移民 action`、连续 `Exception`。

## 6. 上线时机与影响

- **重启会中断所有在线会话**（服务端自动重连，约数十秒）。低峰期执行。
- **必须避开自由移民活动窗口**：若已进入「开放前 15 分钟」准备期，请等本轮窗口结束再部署，
  否则正在准备的任务会走恢复流程（有保护：已发射的任务**不会重发**，但会转 UNKNOWN 需人工核验）。
- 部署后 `data/migrant.json` 首次创建，无需迁移。
