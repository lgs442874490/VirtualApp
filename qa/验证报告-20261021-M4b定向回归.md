## 3. 测试基础设施事件（非产品缺陷，记录备查）

- **中继连接复用引发 nonce 重放拒签**：首版中继（透明 splice）在 HTTP keep-alive 复用下 EOF 处理不当 → OkHttp 对同签名请求（同 nonce）透明重试 → server 重放防护拒签（`验签失败 code=2003`，04:52:58–04:56:18 共 3 组，Broken pipe+2003 成对）。改写中继为单请求单连接（注入 Connection: close）后消失，期间 server/App 均未重启。
  - **副产物**：意外实证了 M1 签名层的 **nonce 重放防护真实有效**（ApiSign.NonceCache，重复 nonce 被拒）。
  - 该期间 App 侧表现为「状态获取失败」横幅（网络错误路径），与产品无关。
- vivo 安装拦截：debug APK 覆盖安装触发「安全守护」确认框（需勾选+继续安装），经 adb 代点完成；不影响结论。
