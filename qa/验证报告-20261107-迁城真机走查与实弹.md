## 3. A9 真机走查

### 3.1 门控链路（本轮最关键发现）

首次走查时**工具箱无迁城卡片**（可用工具 · 4）。根因定位：

- master 已引入「服务端功能矩阵」门控：`FeatureGate.visible()` 在 `featuresPresent=true` 时**只认票据 features 列表**，未命中即隐藏；
- `license-server/features.go` 中 `move_city` 仍是 `implemented=false` → `featuresForRole` 的 `fc.implemented = 1` 过滤把它排除 → 票据 features 21 项不含 `move_city`；
- 实测票据：`"featuresPresent":true, "features":[…dev_monitor, enemy_watch, guardian …watchpoint]`（无 move_city）。

**修复**：`features.go` 置 `implemented=true` + 新增 v2 矩阵迁移（`user_version` 分阶段，只打开 `move_city`，不重放历史阶段以免冲掉运营配置）+ 测试同步。

修复后票据 features **24 项**，含 `move_city` 与 `immigration`；工具箱 **可用工具 · 6**（迁城/移民/观察点/真机抓包/真机监控 + 调试项）。

## 9. 遗留

1. `players_dir.json` 为周期快照，选点时可能过时 → 已用「失败不消耗道具」的螺旋重试兜底；后续可考虑接观察点实时矩形查询做选点预检。
