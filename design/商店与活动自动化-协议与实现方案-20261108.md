## 1. 商店系统

### 1.1 通用协议

```
C2S req_shop_info_array {"arr_id":[1901,3101,1101,...,1701]}   // 批量拉所有商店货架
S2C {"code":0,"map_info":{"<shopId>":{"id":<shopId>,"goods":{
      "1":{"id":1,"conf_id":<配置id>,"buy_count":0,"grid_id":1}, ...},
      "last_refresh_ts":...,"refresh_times":...,"first_refresh_time":...,"expert_count":...}}}

C2S req_shop_info {"shop_id":<shopId>}                          // 单商店（部分商店可用）
S2C {"code":0,"info":{"id":<shopId>,"goods":{...},...}}

C2S req_shop_buy {"shop_id":<shopId>,"goods_id":<货架格id>,"count":<数量>}
S2C {"code":0,"goods":{...},"new_goods":{"id":<同格id>,"conf_id":<新配置id>,"buy_count":0}}  // 801 同格替换
→ 扣费通知：notify_resource_update / notify_backpack_update
→ 限购更新：buy_count（响应 goods.buy_count）

C2S req_shop_refresh {"shop_id":<801|601>}                      // 仅 801/601 支持
S2C {"code":0,"info":{"id":<shopId>,"goods":{...},"refresh_times":n,"first_refresh_time":...}}
```

关键口径：
- `goods_id` 是**货架格子 id**（1..N，或 20-22 专家格），不是 conf_id。
- `conf_id` 是商品配置 id（决定名称/价格/货币/限购）。
- `buy_count` 是该格已购买次数；达到 `limit` 即售罄。
- `new_goods` 仅 801 有（购买后同格替换新商品）；601/301/901 等不替换。
- 刷新：`refresh_times` 累加；免费次数用完后转钻石刷新（价格累加，抓包观察到 100/200 钻）。

### 1.2 各商店清单

#### 301 竞技商店（竞技币）
- 货架：19 格原价 + **3 格专家折扣（grid 20-22）**：
```

30111801 高级野性印记 4800 → 专家格 30112906 2400（5折）
30110301 专精能源石   2500 → 专家格 30112902 1250（5折）
```
- `expert_count` 在 301 为 0，**不能靠它判断专家格**；看 grid 20+ / conf_id `301129xx`。
- 售罄：`buy_count >= limit`（秘银 limit 1，买过即售罄）。
- 不支持刷新。

### 1.3 商品目录配置（shops.json）
- 位置：`app/src/main/assets/towndev/shops.json`（现有 12 个商店：401/501/801/2401/301/601/701/901/1001/1101/1201/2001）。
- 字段：`configId/name/itemId/count/currencyId/currencyName/price/limit`。
- 需补：**1701 峡谷商店**（名称/价格）；1201/1001/901/301/601/801 已有。

### 1.4 购买规则（服务端任务 `shop` 扩展）
```
1. 用户勾选清单（按勾选顺序）持久化到角色参数：
   shop.buy_list = [{"shop_id":301,"conf_id":30112902,"count":1}, ...]
2. 任务运行时：
   a. req_shop_info_array 拉货架
   b. 按 buy_list 顺序遍历：
      - 找货架中 conf_id 匹配的 goods（同 conf_id）
      - buy_count >= limit → 跳过（售罄）
      - 货币余额 < price → 继续下一个（或停止？默认停止=“直到没有货币”）
      - req_shop_buy {shop_id, goods_id, count}
        count = min(剩余限购, 货币可买数)（可配“每次 1 个”）
      - 成功 → 扣减本地货币估算，继续
   c. 601：免费商品默认全买 + 免费刷新全用 + 勾选打折商品刷新到买到
   d. 801：资源商品全买（不保留）+ new_goods 连续买 + 刷新
```
- “直到没有货币”：按勾选顺序，遇到余额不足即停止本轮（或跳过该商品继续？需产品确认，默认停止）。
- 专家格：按 conf_id 精确匹配（301129xx / 90111xxx / 601103xx）。
