## 四、反编译代码确认（`design/research-20261111/wjdr-tool-new`）

### 4.1 `BootstrapService.runNextStepInternal`（803–915）

固定顺序与条件：

1. `renameIfNeeded`
2. **仅当熔炉 ≥7**：`world.advance` → `claimIntelligenceRewards` → `finishPassDue`/`runFinishPass`
3. `buildingsReady && queuesReady` 检查
4. `finishBusyQueue`（30 秒节流，用 `planNext(...,1)` 的首个动作）
5. `tutorial.advance`
6. `mails.advance`
7. `advanceMilestones`
8. 熔炉 ≥3：`rewards.claimCdkeys`
9. `rewards.claimPendingQuests`
10. `heroes.advance`
11. `work.advance`
12. `pendingStorylineStep`（非建筑类）
13. `assignIdleSurvivorToProduction`
14. `planNext(config, state, 8)`
15. `advanceChapterAdventure`
16. `chapterFurnitureAction`
17. `plan.actions().isEmpty()`：
    - 熔炉 ≥7 且 `finishPassDue` → `runFinishPass`
    - `attemptAutomaticAllianceJoin`
    - `COMPLETED` / `WAITING`
18. `executeFirstAction`

### 4.2 51 的处理（1399–1500、2277–2298）

```
51:
  claimBackpackDiamonds
  topUpResources（背包资源包 / 固定箱 / 统帅商店）
  if 熔炉 < 9:
      upgradeWithDiamond → req_upgrade_building {bid, use_diamond:true, qid:0}
      熔炉 ≥5 时再重试一次
      失败 → WAITING「资源或道具不足…」
  if 熔炉 ≥ 9:
      资源不可补足且尝试 ≥3 → ENDED「大熔炉已到 9 级，资源已尽力补充仍不足…」
```

### 4.3 其它与本次相关的条件

- `BootstrapConfig.DEFAULT_TARGET_FURNACE_LEVEL=10`、`MAX_TARGET_FURNACE_LEVEL=10`（本地当前上限 9）。
- `finishPassDue`：熔炉 ≥7 且当日未执行；`runFinishPass` 处理邮箱/签到/里程碑/背包钻石，并再调 `world.advance`。
- 队列秒完：`req_building_queue_speed {qid, use_diamond}` 或 `items:[{id,count}]`；日志出现「已用钻石秒完/已用加速道具秒完」。
- 商店：`req_shop_info`/`req_shop_buy`；购买后自动开安全资源包。
- 入盟：完成时 `attemptAutomaticAllianceJoin`（仅现有联盟，不建盟）。
