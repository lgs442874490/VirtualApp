## D. 任务创建与调度

- [ ] **TC-M13** 创建单个任务（提前量 0）→ 返回 job；大盘出现 WAITING 行；倒计时「距开放 X」
- [ ] **TC-M14** 提前量输入 150 → 输入框上限 100（服务端也钳位 [0,100]）
- [ ] **TC-M15** 同角色再建一个任务 → **被拒**并给出中文原因；大盘不新增
- [ ] **TC-M16** 批量创建 ≥2 账号（含 1 个离线/不同赛区）→ **先弹二次确认**（角色数/目标王国/自动动作摘要）→ 确认后「已创建 n / m」，失败账号逐条列原因
- [ ] **TC-M17** WAITING 任务点「取消」→ 二次确认 → CANCELLED；不再上号、不发射；转入历史
- [ ] **TC-M18** ⚠ 到 `freedom_start-15min` → 服务端自动登录该角色并执行退盟/召回；大盘「召回中」→「已安排回城」；退盟徽标「已自动退出」
- [ ] **TC-M19** ⚠ 回城预计晚于开放前 2 分钟且勾选加速 → 依次消耗二阶→一阶加速器；「加速器 n 二阶 / n 一阶 / n 钻石」递增
- [ ] **TC-M20** ⚠ 背包无召回道具且勾选钻石兜底 → 首次返回 `requires_diamond`，二次确认后以钻石成功（800 钻/次，**每任务上限 10**）
- [ ] **TC-M21** ⚠ 到点发射 → **请求审计**里首发 `sent_at - freedom_start ∈ [-提前量, +50ms]`；`clock_source=role_clock`
- [ ] **TC-M22** ⚠ 迁移成功 → 任务 SUCCEEDED；`reconciled_kid = 目标王国`；历史行「重登王国 K{目标}」
- [ ] **TC-M23** 发射后无响应/断线 → 任务 UNKNOWN；**+3min / +10min 自动复核**后给出结论（无需手动）
- [ ] **TC-M24** 重启 vault-server → `jobs` 任务仍在；WAITING 按剩余时间恢复调度；已过窗口无结果转 UNKNOWN
- [ ] **TC-M24b** ⚠ 崩溃重发防护：在 FIRING 期间强杀进程再启动 → 任务变 UNKNOWN「重启前已发出迁移请求」，**不会**再次自动发射
