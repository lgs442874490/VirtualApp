## 四、关键实现与口径（审查已确认）

| 主题 | 口径 |
|---|---|
| 资源增量消费权 | **批次驱动者独占**：`BootstrapService.syncLoadData(load, consumeChannel=true)` 由批次每轮调用；`BootstrapApi.serviceOf` 的 single-* 传 `false`，只读请求不吞增量。单号单独运行路径不存在（`ACTIVE` 仅批次注册） |
| 会话状态 | `BootstrapSessionState`（按 fpid，进程级）：world/finishPass/ENDED/失败钻石等；`claimWorldKingdomInfo/claimWorldFog/claimFinishPass` 原子认领；`worldAbandoned` 防 release 回摆 |
| R-05 | `WjdrEngine.pendingResUpdate` 按 id 累加、`consumeResourceUpdate()` 原子取走清空；`initialize()/close()` 清理 |
| R-07 耗尽 | `coverable = unsupplied.isEmpty()`；unsupplied 按**成本 − 库存**缺口（`missingOf`），购买数量仍 `force` 全量；商店只买生肉/木材（煤/铁恒计入缺口）；熔炉 ≥9 三次、<9 两次钻石、`!coverable && ≥7 && stall≥10` → ENDED |
| R-03 冷却 | 51 建筑钻石失败写 30s 动作退避 + `buy:` 购买冷却；≥9 分支只写购买冷却（保留计数累积） |
| R-04 去阻塞 | `intelEvents(waitForPush)`：`collectNotifies(2500)` 仅 world 未完成时每轮一次；情报领取用非阻塞读取 |
| R-06 ENDED | `runLeveling` ENDED 优先于 SUCCESS（与 `status().runState` 一致）；`levelBuilding` 也被终态拦截；App 显示「已结束（资源不足）」+ warn |
| R-09 收尾 | 日期取 `ProtocolPort.serverNowMs()`（EnginePort 转发引擎时钟，未校准回退本机），固定 `Asia/Shanghai`；三项全空不占当日 |
| `single-reset` | 新增 API action：清会话状态 + 退避表；**在线（ACTIVE 有会话）时拒绝**；App 未接按钮（新需求） |
